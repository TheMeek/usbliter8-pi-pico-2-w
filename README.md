# usbliter8 Community Firmware

Community firmware collection for **usbliter8**.

This repository provides prebuilt UF2 firmware for various RP2350 development boards, including both self-built firmware and community-contributed builds.

> This is **NOT** the official usbliter8 repository.
> All credits for the original exploit and implementation belong to the original usbliter8 authors.

## Available Boards

Currently available firmware includes:

- Waveshare RP2350-USB-A
- Waveshare RP2350-USB-C
- Waveshare RP2350-USB-CM
- Waveshare RP2350-Zero
- Waveshare RP2350-Pizero
- Raspberry Pi Pico 2
- Pimoroni Tiny2350

## Firmware

Each firmware image is provided as a precompiled UF2 file.

Please choose the firmware that matches your board.
